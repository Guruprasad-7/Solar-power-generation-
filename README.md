# ☀️ Solar Power Generation Prediction System

An interactive **Streamlit-based Machine Learning application** that analyzes solar power data and predicts solar energy generation using a **Gradient Boosting Regression model**.

## 📌 Project Overview
Solar power forecasting plays a crucial role in renewable energy planning.  
This project provides a complete end-to-end solution that includes:

- Data loading and preprocessing
- Interactive data exploration
- Visualization of trends and correlations
- Feature importance analysis
- Real-time solar power prediction using Machine Learning

The application is designed to be user-friendly and deployment-ready.

- Time Series Plot of Solar Power Generation
- Scatter Matrix for selected features
- Correlation Heatmap
- Feature Importance Bar Chart

## 🤖 Machine Learning Model
- **Model:** Gradient Boosting Regressor
- **Preprocessing:** Feature scaling using a saved scaler
- **Target Variable:** Last numeric column in dataset
- **Optimization:** Auto-adjusts feature count to match model requirements

## 🔮 Prediction Workflow
1. User enters feature values via the Streamlit form
2. Inputs are scaled using the trained scaler
3. Gradient Boosting model predicts solar power generation
4. Prediction result is displayed instantly
